# RedYA AI for Xiaohongshu

This skill helps Xiaohongshu creators and ecommerce teams draft Chinese-language illustrated posts, prepare product posts from their own photos, and turn still photos into Live Photos. It can check draft copy for sensitive terms. Users review their results before publishing them in Xiaohongshu.

Create an API key in the **红鸦 Skills** section at [RedYA AI](https://hy.ithinkai.cn) and configure it as `REDYA_API_KEY` in your agent environment. Use the default RedYA endpoint for this listing. The skill is free to install. Some RedYA API operations charge credits to your RedYA account. Review RedYA's current quote before confirming paid Live generation.

The agent sends your topic and selected material to RedYA, checks task status, and can save returned assets in your working directory. Provide only photos and material you have permission to use.
